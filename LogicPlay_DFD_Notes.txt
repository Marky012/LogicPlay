LOGICPLAY SYSTEM - DATA FLOW DIAGRAM (DFD) NOTES
=========================================================

1. LEVEL 0: CONTEXT DIAGRAM
---------------------------
EXTERNAL ENTITIES:
- Student
- Teacher

PROCESS:
[P0] LogicPlay System

DATA FLOWS:
- Student -> Login/Registration Info -> [P0]
- [P0] -> Auth Token / Profile Data -> Student
- Student -> Join Code / Enrollment Request -> [P0]
- Student -> Circuit Submission Data -> [P0]
- [P0] -> Mission Report / Feedback / Points -> Student
- Teacher -> Login/Registration Info -> [P0]
- Teacher -> Classroom / Assignment Data -> [P0]
- [P0] -> Student Submissions / Performance Data -> Teacher
- Teacher -> Grades / Feedback -> [P0]


2. LEVEL 1: LOGICAL DFD (KEY PROCESSES)
---------------------------------------

[P1] USER AUTHENTICATION
- Input: Username/Password from Student/Teacher
- Output: Auth Token, User Profile (Role, Points, Level)
- Data Store: [D1] Users

[P2] CLASSROOM MANAGEMENT
- Input: Classroom Info (Name) from Teacher
- Input: Join Code from Student
- Output: Join Confirmation, Classroom List
- Data Store: [D1] Users, [D2] Classrooms, [D3] Enrollments

[P3] CIRCUIT DESIGN & SIMULATION
- Input: Gate Placements, Wire Connections from Student/Teacher
- Input: Save/Load Requests
- Output: Real-time Simulation Results, Saved Circuits
- Data Store: [D4] Circuits

[P4] ASSIGNMENT & SUBMISSION MANAGEMENT
- Input: Assignment Details (Target Gate, Due Date) from Teacher
- Input: Circuit Submission from Student
- Output: Status Updates, Submitted Assignments for Teacher
- Data Store: [D5] Assignments, [D6] Submissions

[P5] EVALUATION & GRADING
- Input: Grade/Feedback from Teacher
- Input: Auto-score results from System
- Output: Graded Mission Reports to Student
- Data Store: [D6] Submissions, [D1] Users (for points/level up)

[P6] GAMIFICATION & PROGRESSION
- Input: Points earned from Submissions/Challenges
- Output: Badges, Level Up Notifications
- Data Store: [D1] Users, [D7] Badges, [D8] Challenges


3. DATA STORES (DS) SUMMARY
---------------------------
[D1] Users (Account details, Points, Levels)
[D2] Classrooms (Name, Join Codes)
[D3] Enrollments (Student-to-Class linking)
[D4] Circuits (Saved canvas data)
[D5] Assignments (Teacher tasks)
[D6] Submissions (Student work for assignments)
[D7] Badges (Achievement definitions)
[D8] Challenges (Individual logic missions)

---------------------------------------------------------
DFD PROCESS SUMMARY:
1. Teacher creates Classroom and Assignment [P2/P4].
2. Student joins Classroom using Join Code [P2].
3. Student designs circuit in Canvas [P3].
4. Student submits circuit for Assignment [P4].
5. System/Teacher evaluates submission [P5].
6. Student receives Feedback, Points, and Badges [P5/P6].
---------------------------------------------------------
