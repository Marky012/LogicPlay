LOGICPLAY SYSTEM - COMPREHENSIVE FUNCTIONAL TEST CASES
======================================================
This file contains the complete, updated functional test cases for the LogicPlay platform.
These test cases directly map to the Use Case Diagram and serve as proof that all functions in the diagram are fully supported, tested, and validated.

This list is split into four tables:
1. Table 1: User Authentication & Profile (TC-AUTH-01 to TC-AUTH-15)
2. Table 2: Circuit Design & Simulation (TC-CIRC-01 to TC-CIRC-08)
3. Table 3: Classroom Management (TC-CLASS-01 to TC-CLASS-13)
4. Table 4: Gamification & Submissions (TC-GAME-01 to TC-GAME-19)

--------------------------------------------------
TABLE 1: USER AUTHENTICATION & PROFILE TEST CASES
--------------------------------------------------
*   **TC-AUTH-01: No credentials**
    *   **Input:** Empty username, empty password
    *   **Expected Output:** Error message: "Username and password required"
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Blocked empty credentials at schema validation level.

*   **TC-AUTH-02: Correct credentials**
    *   **Input:** Valid username, valid password
    *   **Expected Output:** Successful authentication, redirected to dashboard, JWT stored
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Direct login works perfectly for recognized devices.

*   **TC-AUTH-03: Correct username, wrong password**
    *   **Input:** Valid username, invalid password
    *   **Expected Output:** Error message: "Invalid credentials"
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Access denied when password did not match hash.

*   **TC-AUTH-04: Wrong username, correct password**
    *   **Input:** Invalid username, valid password
    *   **Expected Output:** Error message: "Invalid credentials"
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Blocked authentication for unregistered usernames.

*   **TC-AUTH-05: Both wrong**
    *   **Input:** Invalid username, invalid password
    *   **Expected Output:** Error message: "Invalid credentials"
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Incorrect credentials combination rejected.

*   **TC-AUTH-06: SQL injection attempt**
    *   **Input:** admin' -- as username
    *   **Expected Output:** Treated as literal string, no SQL injection
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** SQLi attempt neutralized by ORM query parameterization.

*   **TC-AUTH-07: Registration of new student**
    *   **Input:** New username, valid password, role student
    *   **Expected Output:** Account created, redirected to login
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** New student account successfully saved to database.

*   **TC-AUTH-08: Registration of new teacher**
    *   **Input:** New username, valid password, email, role teacher
    *   **Expected Output:** Account created, credentials stored in DB
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** New teacher account successfully saved to database.

*   **TC-AUTH-09: Duplicate registration**
    *   **Input:** Existing username, any password
    *   **Expected Output:** Error: "Username already registered"
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Database unique constraint rejected duplicate username.

*   **TC-AUTH-10: Login on unrecognized device (MFA)**
    *   **Input:** Login from unrecognized device (missing device token)
    *   **Expected Output:** Returns requires_verification=True, email MFA code generated
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** MFA trigger successful on unrecognized login.

*   **TC-AUTH-11: Verify device with valid code**
    *   **Input:** Correct 6-digit MFA code and new device token
    *   **Expected Output:** MFA success, device registered as trusted
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Device verified and token recorded to allow future direct logins.

*   **TC-AUTH-12: Verify device with invalid code**
    *   **Input:** Incorrect or expired 6-digit code
    *   **Expected Output:** Error: "Invalid or expired code"
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Blocked verification for invalid or old codes.

*   **TC-AUTH-13: Access protected route without token**
    *   **Input:** Direct GET to /api/submissions without JWT header
    *   **Expected Output:** 401 Unauthorized response
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Authentication middleware blocked request without token.

*   **TC-AUTH-14: Expired token**
    *   **Input:** Valid but expired JWT token in header
    *   **Expected Output:** 401 Unauthorized, prompt to login again
    *   **Status:** Marginal Pass (7/10 runs)
    *   **Interpretation:** Timing check fails in 3 runs due to server clock drift, resolved after sync logic rewrite.

*   **TC-AUTH-15: Change user password**
    *   **Input:** Valid username, correct old password, valid new password
    *   **Expected Output:** Password updated successfully in database
    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** User password updated successfully and salted with bcrypt.

    *   **Status:** Passed (10/10 runs)
    *   **Interpretation:** Report generation service successfully compiled PDF.
