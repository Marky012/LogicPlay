FORMAT 3: STRUCTURED PLAIN TEXT DESCRIPTION
--------------------------------------------------
This structure is ideal to paste directly into AI diagram makers (like Eraser.io, Draw.io, or ChatGPT/Claude) to instruct them on how to generate the diagram.

**System Boundary:** LogicPlay System

**Actors:**
1. **Student** (Primary Actor - User who learns logic gate circuit design)
2. **Teacher** (Primary Actor - User who manages classrooms, tasks, and grades)
3. **Autograding System** (Secondary System Actor - Automates verification & scoring of circuits)

**Use Cases by Actor:**

*   **Student Use Cases:**
    *   *Register Account*: Sign up to the system as a student.
    *   *Login / Authenticate*: Authenticate username/password.
        *   *Verify Device (MFA)*: (Optional extension) Enter 6-digit email verification code for unrecognized devices.
    *   *Change Password / Edit Profile*: Update personal details and password.
    *   *Join Classroom*: Enter a unique 6-character Join Code to enroll in a classroom.
    *   *Design Logic Circuit*: Drag-and-drop gates (AND, OR, NOT, NAND, NOR, XOR, XNOR, inputs/outputs) on a panning/zooming canvas.
    *   *Simulate Circuit Logic*: View real-time signal flows and binary pulse animations.
    *   *Save / Load Circuit*: Save canvas state to the backend (or IndexedDB if offline).
    *   *Offline Save & Sync*: Work offline and automatically synchronize saved circuits when connection is restored.
    *   *Generate Circuit Report*: Export a PDF/soft copy report containing name, truth table, and circuit diagram.
    *   *View Active Assignments*: View list of tasks assigned by teachers.
    *   *Dismiss / Reset Assignments*: Hide tasks from view or restore hidden lists.
    *   *Submit Circuit for Assignment*: Send completed circuits to assignments (triggers *Auto-Score*).
    *   *View Submissions*: Check feedback, points, and grades of submitted work.
    *   *View Leaderboard*: View list of top students by XP/Points.
    *   *Track XP, Level, & Badges*: Monitor game progression and achievements.
    *   *View Challenges*: View list of independent logic missions.

*   **Teacher Use Cases:**
    *   *Register Account*: Sign up as a teacher.
    *   *Login / Authenticate*: Authenticate username/password.
        *   *Verify Device (MFA)*: (Optional extension) Enter 6-digit email verification code for unrecognized devices.
    *   *Change Password / Edit Profile*: Update personal details and password.
    *   *Create Classroom*: Create a new classroom group and generate a unique join code (with optional Teacher Approval option).
    *   *Manage Classroom Details*: Edit classroom name, regenerate join codes, or delete classrooms.
    *   *Approve Student Enrollments*: Review and approve pending student enrollment requests.
    *   *Remove Student from Class*: Deregister student from a classroom.
    *   *View Classroom Analytics / Dashboard*: Track real-time dashboard of student lists and submission statistics.
    *   *Create Assignment*: Define task title, description, target gate hints, deadlines, and rewards.
    *   *Edit / Delete Assignment*: Update details or remove assignments.
    *   *View Submissions List*: Review all students' work submitted for assignments.
    *   *Grade & Feedback Submission Manually*: Input teacher score and comment feedback on student submissions.
    *   *Design Logic Circuit / Simulate / Save*: Access the playground for demo purposes.
    *   *View Leaderboard*: View general student rankings.

*   **Use-Case Relationships:**
    *   **Include:** "Submit Circuit for Assignment" *includes* "Auto-Score Circuit Submission".
    *   **Extend:** "Login / Authenticate" *is extended by* "Verify Device (MFA)" if the device is unrecognized.
    *   **Secondary Actor Association:** "Auto-Score Circuit Submission" connects to the "Autograding System".
